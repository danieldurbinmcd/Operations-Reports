Daily Execution Guide
Supervisor Reference click to expand ▼
① Labor — Set Up to Win
Labor is not a day-of activity — it is a system built 1–2 weeks in advance. If labor is wrong this week, the failure happened last week.

Non-Negotiable Checks:
  • No unassigned shifts — every shift is filled
  • Variable hours align to VLH guidelines
  • Scheduled TPPH matches target TPPH
  • Peak periods properly staffed and deployed
If the schedule does not align with VLH and TPPH targets, the operation is set up to fail before the week begins.
② Evaluate Results — Daily Order
Review in this order:
  1. Sales & Transactions — QSRSoft / Daily Labor Sheet
    What happened — not why
  2. Labor Results — Hours vs Plan, TPPH vs Target
    Did labor create the capacity to win?
  3. Service KPIs — By daypart & hour
    Service exposes execution
  4. Operations Metrics — Deployment, positions, breaks
    Operations reveal leadership
③ Diagnose the System
Diagnose in reverse order:
Labor → Operations → Service → Sales

Critical Question: Is this a demand problem or an execution problem?

❌ "Sales were down" / "Service was slow"
✅ "What decision created this outcome?"
✅ "Was this a planning failure or an execution failure?"
If you did not identify the root cause, you did not solve the problem.
④ Focus — Top 1–2 Problems
Not all problems matter equally. Identify the top 1–2 system problems and top 1–2 leadership gaps.

You are not solving every problem — you are ensuring the right problems are owned.

Ask: Is this complicated or complex? A complicated problem has a known fix. A complex problem requires a new approach.
⑤ Develop the GM — Multiply Ownership
You do not solve the problem. You develop the person who will.

Every conversation must drive 3 outcomes:
  • Clarity — Do they see the real problem?
  • Ownership — Do they own the result?
  • Adjustment — What will they do differently?
If the GM leaves without ownership, the problem remains yours.

How to Read Your Score

1.00 means you meet the standard on balance. Above 1.00, you're ahead. Below, you're behind. Scores are capped at 0.50–1.50 so no single extreme metric can dominate the composite.

Effective DT Time (50% weight) — Timer OEPE + Parked% × Parked Time. Uses the magnetic plate timer (ungameable) where coverage is ≥ 80%. Falls back to bump basis with a red flag when timer is unavailable. Standard: 130s.

R2P Front Counter (20% weight) — Receipt-to-present time at front counter. Gated: below 30s scores 0.85 penalty (physically impossible — investigate receipt-timing practices). Standard: 45s.

KVS Time/Item (30% weight) — Production speed per item, not per order. A restaurant building complex orders is not penalized. Gated: below 50% healthy usage scores neutral 1.00 (data unreliable); below 12s/item scores 0.85 penalty (impossible number — investigate bump practices). Standard: 18s/item.

HUSS / Side-2 Deployment (variable weight by location volume) — Bump discipline integrity. Standard: 80%. Below 50% triggers the KVS trust gate above.

3PO Delivery Index (conditional, up to 15% weight) — Only for restaurants doing meaningful weekly delivery volume. Measures restaurant handoff time (60% weight) and order accuracy (40% weight). Driver drive time and courier ratings are not counted against you. Standard: 3.0 min handoff, 98% accuracy.
